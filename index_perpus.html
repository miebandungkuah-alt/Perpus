Pengaturan Multi-PC Sync (Database Cloud)

Agar 3 PC dapat saling terhubung secara real-time, masukkan kunci konfigurasi dari Firebase Firestore (Gratis) di bawah ini. Cukup masukkan sekali di tiap PC.

Cara cepat membuat Database Firebase Gratis (2 Menit):

  1. Buka console.firebase.google.com & login Google
  2. Buat project baru, lalu tambahkan App Web (</>)
  3. Salin `firebaseConfig` dan paste ke kotak di atas
  4. Buka menu Firestore Database → Create Database → Start in Test Mode
